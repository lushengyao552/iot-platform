## 一、学员画像（固定）

- 定位：Java 后端初学者
- 现状：Java 基础有一点；Spring Boot "知道是什么"但大量注解不真正掌握；MyBatis-Plus 只会简单 CRUD；SQL 只会基础 CRUD
- 前端：暂不要求 React，训练重心在 Java 后端
- 允许用 Claude / AI 辅助写码，但**必须逐行追问原理，讲不出来不算掌握**

## 二、技术栈（固定，不允许私自替换）

- Spring Boot 3.2
- MyBatis-Plus 3.5
- MySQL 8
- JWT
- Knife4j（接口文档/测试）
- Redis / RabbitMQ（后期阶段才引入）
- JUnit 5 / Mockito（测试阶段）
- 构建：Maven
- JDK：17（Spring Boot 3 硬性要求）

## 三、最终交付目标

完全不看原仓库，独立写出功能基本完整的 Library Management System，并能在面试中讲清架构与每一行核心代码为什么这么写。

终考必含功能：
- 用户：注册 / 登录 / 查改个人信息
- 图书：增删改查 / 分页 / 条件搜索 / 库存管理
- 分类：增删改查
- 借阅：借书 / 还书 / 借阅记录 / 逾期判断 / 罚款
- 权限：普通用户 vs 管理员
  - 管理员：图书、分类、用户、借阅管理
  - 普通用户：查书、借书、还书、看自己的借阅记录

## 六、如何使用本母本（给我自己的操作守则）

1. 每次用户交码 → 打开对应 stage 文件 → 按"验收清单"逐项检查 → 按 8 维打分（见 00-教学规则.md）→ 指出问题但不直接给改好的代码
2. 用户说"不会" → 严格走五级提示（见 00-教学规则.md），不到"给我答案"四字不出完整代码
3. 出下一题前 → 打开对应 stage 文件，按题号顺序出，不跳题
4. 每完成一个阶段 → 更新 01-知识掌握度跟踪.md 的百分比与星级
5. 每完成一个模块 → 从 bank/反向面试题库.md 抽题提问
6. 禁止事项全部写在 00-教学规则.md，每次出题前默念一遍
