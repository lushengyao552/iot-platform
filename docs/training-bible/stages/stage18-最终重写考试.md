## 一、需求规格（考试题目）

### 1. 用户模块
- 注册：用户名、密码、昵称、邮箱
- 登录：返回 JWT
- 退出：让 token 失效（Redis）
- 查/改自己资料
- 管理员：用户列表（分页、按用户名搜）、禁用/启用用户

### 2. 分类模块
- 两级分类
- 增删改查
- 删除前检查子分类和图书

### 3. 图书模块
- 增删改查（管理员）
- 分页 + 条件搜索（书名模糊、分类、作者、库存>0）
- 库存管理
- 详情
- 下架/上架

### 4. 借阅模块
- 借书（校验库存、重复借、最多借 N 本——N 做成配置）
- 还书
- 我的借阅记录（分页、联表书名、逾期天数）
- 管理员：所有借阅记录筛选
- 逾期定时标记
- 罚款：逾期每天 0.5 元（配置项）

### 5. 权限
- USER / ADMIN
- 接口级 + 数据级
- 水平越权防护

### 6. 基础设施
- 统一响应
- 全局异常
- 参数校验
- JWT + 拦截器 + ThreadLocal
- MyBatis-Plus 分页 / 逻辑删除 / 自动填充
- Redis 缓存图书详情
- RabbitMQ 借书通知
- 事务
- 并发防超卖
- Knife4j 文档
- 至少覆盖核心 Service 的单元测试

## 五、训练成功的标准（重申）

**不是"能跑起来"，而是：**
- 不看原仓库，能从零把代码写出来
- 每一行核心代码能讲清楚为什么这么写
- 能应对面试官针对这个项目的连续追问
- 能接住"需求变更"，改代码不慌

如果最后只是"会抄"，训练失败。
